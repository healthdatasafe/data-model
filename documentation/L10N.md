# Translations

The definitions carry `en` and `fr` (both required where a schema says so) and a few `es`, `de`, `it` written there. Every
other text of a locale is in `definitions/l10n/{locale}.json` and is added to the published files by the build
(`src/l10n.js`). Consumers read the same files: a text map simply has more keys.

```json
{ "items.json": { "body-weight/label": { "en": "Body weight", "text": "Peso", "reviewedBy": "…", "reviewedOn": "2026-12-01" } } }
{ "items.json": { "body-weight/label": { "en": "Body weight", "text": "Peso", "status": "draft" } } }
```

- **Locales:** five full locales, `en`, `fr`, `es`, `it`, `pt-BR`; `de` covers document kinds only. `pt` (European) would be
  the sixth and goes to files loaded on demand (§ Size). The added locales are the ones hds-lib supports (`localizeText.ts`).
- **Reviewed or marked draft** (decision of 2026-11-25). A text is reviewed (`reviewedBy`, `reviewedOn`) or a draft
  (`"status": "draft"`, no reviewer; a machine draft, say). Any other shape fails the build. A reviewed text replaces the
  draft in the same entry.
- **A text map does not mark drafts:** `{ "en": …, "it": … }` reads the same, draft or reviewed. The mark is per locale, in
  `pack.json` `"l10n": { "<locale>": { "status": "draft" | "reviewed" } }`, for the locales of `definitions/l10n` only:
  `draft` when one of its published texts is a draft. A reader that shows the texts to a third party or on a consent
  screen reads it there.
- **The build fails** on a text whose English changed, a path or a published file that
  does not exist, an empty text, a text also in the
  definitions, two array entries with one value or id, an unknown locale. To change an English text, change or delete
  its translations in the same commit.
- **`do-not-translate.json`**: `[{ "file", "path", "reason" }]`, texts of licensed or validated instruments. A translation
  of one is reviewed, never a draft, and needs `"official": "<source>"`.
- **Path:** the published file name, then object keys joined with `/` (`~1` for `/`, `~0` for `~`); an array entry is
  `[value=<JSON>]` or `[id=<JSON>]` when it has one, else `[index]`.
- **Converter packs are frozen** (AGENTS.md § Versions): their texts are published in `converters/{key}/l10n-{locale}.json`
  (`{ locale, status, packs: { "pack-v1.json": { "<path>": "text" } } }`, `status` that of the locale in `pack.json`), which
  may change. hds-lib 2.70.0 and later read it (`converters.loadTexts()`). A new converter version has no block until one
  is added: copy the previous pack's block under the new file name, or its texts stay English (the build does not warn).
- **Checked again after the merge:** item, vocabulary and document-kind schemas, document-kind labels unique per language,
  stream labels distinct on a consent screen.
- **Version:** a new locale is a minor, a corrected translation a patch.
- **Size:** a locale adds about 90 KB to `pack.json` (17 KB gzip). At 2 MB raw, 300 KB gzip or a sixth locale, new locales go
  to files loaded on demand instead.
